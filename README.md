# Rondo — Releases

**Rondo** is a macOS agent workspace app — open a local Vault (folder) and its structure, instructions, and memory become the context for AI CLI agents (Claude Code / Codex).

> *Where work becomes context. Human stays in the loop.*

- 🌐 Website: https://tryrondo.com
- ⬇️ Download: see [Releases](https://github.com/dave-jin/rondo-releases/releases/latest) — `Rondo-<version>-arm64.dmg` (Apple Silicon)

## Beta notice

Rondo is in early beta and not yet notarized by Apple. On first launch, macOS Gatekeeper may block the app:

1. Open the DMG and drag **Rondo** to Applications
2. **Right-click** (or Control-click) `Rondo.app` → **Open** → **Open** again

Requires macOS on Apple Silicon (arm64).

*This repository hosts release binaries only — the source code lives in a private repository.*
